# MOJBack-end
## API - Task Manager

## Installation
1. Close the repository: `git clone https://github.com/swoody2527/MOJBack-end/`
2. Enter the repo: `cd MOJBack-end`
3. Optionally create a virtual environment with `python -m venv venv`
4. Install dependencies: `pip install -r requirements.txt`
5. Run the application: `fastapi dev app/main.py`

API root hosted at: `http://127.0.0.1:8000`
Interactive API docs at: `http://127.0.0.1:8000/docs`
